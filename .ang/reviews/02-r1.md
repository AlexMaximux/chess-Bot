1. **[Medium] `engine/selector.py:97-100` mate-in-1 guard can still pick a losing move.** If every move in
   `pool` allows mate-in-1, the code keeps the unsafe pool even when another candidate (or another legal
   move) is safe. Required order: safe moves in pool → safe moves among all candidates (pick the lowest loss)
   → any safe legal move not in candidates (prefer checks/captures, else first) → only then the unsafe pool.
   Add a test where all pool moves allow mate but a worse candidate does not.

2. **[Medium] `human/timing.py:102-110` speed multiplier is applied after the clock caps.** With `speed < 1`
   the result breaks the caps (a 1.5 s cap becomes 3 s at speed 0.5). Apply speed first, then the clock caps.
   Add a test: `clock_seconds=10, speed=0.5` → result ≤ 1.5 s.

3. **[Low] `human/timing.py:26-32` recapture check without a move stack** assumes the last move was a capture
   when the chosen move is a capture. Without a move stack (fallback board), return False unless `last_move`
   is given and the board before it can be known. Add a test.
