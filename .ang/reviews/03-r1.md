# Review: brief 03 (and 02-r1), round 1

Good work: gates pass (110 tests, mypy, ruff), both live games won, 02-r1 items fixed correctly.
Fix these before brief 04. Commit as `brief 03 r1: review fixes`. Add a test for every item marked (test).

1. **[High] `bot/controller.py:213-224` game over / new game is broken.** Line 220 checks
   `not snapshot.game_over` inside `if snapshot.game_over:`, so it is always false (dead code). When the
   user closes the game-over modal, the final position is treated as a live game: if we were mated,
   the engine gets a finished position (no lines, `ERROR`); after a draw or resignation with legal moves
   left, the bot could move in a finished game.
   Required:
   - Latch game over: once `GAME_OVER`, stay there until a **new game** is detected, even if the modal is closed.
     New game = the move list is empty or shorter than at game end, or the board is the start position.
   - Treat a board that `is_game_over()` (python-chess) as `GAME_OVER` too, modal or not.
   - On a new game, reset all per-game state: `_last_seen_ply`, `_retry_count`, `_override_style`,
     stable-read counters, `_pieces_source_start_time`.
   - (test) game over → modal closed, final position still shown → no input; then new game → plays.
   - Live: in **one** `run` session, play two games in a row. Start the second game yourself with a dev
     script (the bot itself must not click "New game"). Save the log in `docs/live-runs/`.

2. **[High] URL guard only runs at the top of the loop.** The think wait can last 10+ s. Re-check
   `is_allowed_url` immediately before every `perform_move` (including the retry) and during the think
   wait. If not allowed: abandon the move, go to `BLOCKED_URL`. (test: URL changes during thinking → no input.)

3. **[High] `chrome/page.py:61-67` and `run --start-url` bring back tab hijacking.** With a non-allowed
   `start_url`, `find_or_create_chess_tab` returns any tab whose URL starts with it (for example the
   user's live game on `/play/online`) and attaches to it. Remove that block and the `--start-url` flag.
   `Settings.start_url` must be an allowed URL; if not, log a warning and use the default.
   For the BLOCKED_URL acceptance check, use a dev script (`scripts/dev_blocked_url.py`) that starts the
   controller on the bot's own allowed tab and then navigates **that same tab** to
   `https://www.chess.com/play/online`. The bot must report `BLOCKED_URL` and send no input.
   (test: `find_or_create_chess_tab` with only a `/play/online` tab never returns it.)

4. **[Medium] Reconnect does not reconnect.** `_fetch_snapshot_with_retry` retries on the same
   `CDPClient`; after `ConnectionLost` that client is closed, so every retry fails. Implement a real
   reconnect: inject a `reconnect` coroutine factory into the controller (testable with fakes). It
   attaches to the debug port again (do **not** launch a new Chrome; if the port does not answer, give a
   clear "Chrome was closed" error), finds the allowed tab again, attaches a new `ChessPage`, and
   rebuilds the input handler on the new page. Backoff 1, 2, 5, 10 s, then `ERROR` + paused.
   (test: connection lost → reconnect called → play continues.)

5. **[Medium] `input/cdp_input.py` can leave the mouse button pressed.** If a CDP send fails mid-drag,
   `_mouse_pressed` stays true and nothing releases it until `close()`. Use `try/finally` in the drag and
   click paths to send `mouseReleased` when a press is active. The controller must also call a release on
   input error. Same for `os_input.py`. (test)

6. **[Medium] `reader.js` logged-in username can pick the wrong link.** `querySelectorAll` with a selector
   list returns elements in **document order**, and the list ends with the generic
   `a[href*="/member/"]`. A profile link inside a player box (for example the bot's name) can be picked
   first, and then our colour is wrong. Remove the generic selector. Only read nav/sidebar containers, and
   skip any link inside `#board-layout-player-top`, `#board-layout-player-bottom`, `#board-layout-main`,
   or the board. If you can only test as a guest, say so in the report.
